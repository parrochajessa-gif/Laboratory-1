# Cloud Provider Comparison

Cloud providers offer similar infrastructure capabilities but use different names for their services. This comparison focuses on compute, storage, networking, and identity and access management.

## Infrastructure Service Comparison

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Compute | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Storage | Amazon S3 | Azure Blob Storage | Cloud Storage |
| Networking | Amazon VPC | Azure Virtual Network | Virtual Private Cloud (VPC) |
| Identity and Access Management (IAM) | AWS IAM | Microsoft Entra ID / Azure RBAC | Cloud IAM |

## Compute

Amazon EC2 provides virtual servers that can be used to run applications and workloads. Azure Virtual Machines provides virtual machines in Microsoft Azure, while Google Compute Engine provides virtual machine instances in Google Cloud.

## Storage

Amazon S3 is an object storage service used to store files and other data. Azure Blob Storage provides object storage in Azure, while Google Cloud Storage provides scalable object storage using buckets.

## Networking

Amazon VPC provides a virtual network for AWS resources. Azure Virtual Network provides private networking for Azure resources, while Google Cloud VPC provides networking for Google Cloud workloads.

## Identity and Access Management

AWS IAM manages access to AWS resources and permissions. Microsoft Entra ID and Azure role-based access control provide identity and access management in Microsoft's cloud environment. Google Cloud IAM manages permissions for Google Cloud resources.

# Guide Questions

## 1. Which cloud provider offers the broadest range of services? Explain your answer.

AWS is commonly recognized as one of the cloud providers with the broadest range of services. It provides services covering computing, storage, databases, networking, security, analytics, artificial intelligence, monitoring, and many other areas. This gives organizations many choices when designing cloud systems.

## 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

I would recommend Microsoft Azure because it works closely with Microsoft's existing products and technologies. Organizations already using Microsoft services and Windows-based systems may find it easier to integrate their existing environment with Azure.

## 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?

Google Cloud Platform is widely recognized for its strong AI, machine learning, and Kubernetes capabilities. Google created Kubernetes and provides Google Kubernetes Engine (GKE), along with various AI and machine learning services.

AWS and Microsoft Azure also provide strong AI, machine learning, and Kubernetes services.

## 4. What similarities did you observe among the three cloud providers?

The three cloud providers offer similar fundamental infrastructure services even though their service names are different. All three provide computing, storage, networking, and identity and access management services. They also provide tools for managing resources and allow organizations to scale their infrastructure based on their needs.
