# Mission Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?

For me, compute is one of the most important cloud infrastructure components because it provides the processing power needed to run applications and services. Without enough CPU and memory, a system may become slow or unable to handle its workload. Storage and networking are also important, but compute is what allows applications to actually process tasks.

## 2. How does Linux support cloud computing?

Linux supports cloud computing by providing a flexible and reliable operating system for servers and cloud workloads. During this laboratory, I used Linux commands to investigate the operating system, kernel, CPU, memory, storage, filesystem, hostname, and IP address. This helped me understand how cloud engineers can inspect and manage server environments through the command line.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it records the resources available and explains how the infrastructure is organized. It gives engineers a reference before deploying or changing a system. Good documentation can also reduce mistakes and help other team members understand the planned environment.

## 4. What new skills did you learn during this laboratory activity?

I learned how to investigate a Linux server using commands such as `lscpu`, `free`, `lsblk`, `df`, `hostname`, and `hostname -I`. I also learned more about the differences between compute, storage, networking, and identity services. Another skill I practiced was creating organized Markdown documentation and maintaining a structured GitHub portfolio.

## 5. How has your GitHub portfolio improved after completing this mission?

My GitHub portfolio became more organized because I added a complete laboratory folder containing technical documentation, server investigation results, screenshots, a cloud provider comparison, and an infrastructure diagram. It now shows not only my answers but also evidence of the technical work I performed. This makes the portfolio more useful for demonstrating my cloud computing skills.
