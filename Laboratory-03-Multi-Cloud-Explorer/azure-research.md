# Microsoft Azure Research

## Brief Overview
Microsoft Azure is Microsoft's cloud computing platform, launched in 2010, offering a wide range of services including computing, analytics, storage, and networking. It is especially known for its deep integration with Microsoft's enterprise software ecosystem.

## Global Infrastructure
Azure operates in more datacenter regions than any other cloud provider, spanning over 70 regions across dozens of countries. Many regions offer Availability Zones — physically separate locations within a region — to help organizations build resilient, highly available applications.

## Cloud Management Console
The Azure Portal is the web-based, unified console for building, managing, and monitoring Azure resources. It provides a customizable dashboard where users can access all Azure services, manage subscriptions and billing, configure security settings, and monitor resource health.

## Four Core Services
1. **Virtual Machines** – On-demand, scalable computing resources similar to AWS EC2.
2. **Blob Storage** – Object storage solution for unstructured data such as documents, images, and backups.
3. **Azure SQL Database** – Fully managed relational database service built on SQL Server.
4. **Virtual Network** – Enables secure, isolated networking between Azure resources.

## Three Advantages
1. Deepest integration with Microsoft products such as Windows Server, Active Directory, and Microsoft 365.
2. Largest number of global regions of any cloud provider, helping meet data residency requirements.
3. Strong hybrid cloud support, allowing organizations to connect on-premises infrastructure to the cloud smoothly.

## Typical Enterprise Use Cases
- Organizations already using Microsoft products migrating to the cloud
- Hybrid cloud deployments (on-premises + cloud)
- Enterprise identity and access management via Active Directory integration
- Business application hosting and modernization
