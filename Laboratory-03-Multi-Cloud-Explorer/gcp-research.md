# Google Cloud Platform Research

## Brief Overview
Google Cloud Platform (GCP) is Google's suite of cloud computing services, which began in 2008 with Google App Engine. GCP runs on the same infrastructure Google uses for its own products like Search and YouTube, and is particularly strong in data analytics, AI/ML, and container orchestration.

## Global Infrastructure
GCP operates in over 40 regions worldwide, each containing multiple zones — isolated deployment areas within a region. This structure allows applications to be distributed for high availability and fault tolerance, similar to AWS and Azure's models.

## Cloud Management Console
The Google Cloud Console is the web-based graphical interface for managing GCP resources. It allows users to deploy and monitor services, manage billing, configure identity and access permissions, and use built-in tools like Cloud Shell for command-line access.

## Four Core Services
1. **Compute Engine** – Virtual machines for running workloads, GCP's equivalent to EC2.
2. **Cloud Storage** – Scalable object storage for unstructured data.
3. **Cloud SQL** – Fully managed relational database service.
4. **Virtual Private Cloud (VPC)** – Provides networking functionality for GCP resources.

## Three Advantages
1. Strong leadership in AI/ML tooling and data analytics services.
2. Origin and continued strong support of Kubernetes, since Google created the technology.
3. Generally simpler, more transparent pricing compared to competitors.

## Typical Enterprise Use Cases
- Big data analytics and business intelligence
- AI/ML model development and training
- Kubernetes-based container deployments
- Startups and data-heavy applications
