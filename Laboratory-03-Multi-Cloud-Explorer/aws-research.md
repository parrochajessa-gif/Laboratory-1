# AWS Research

## Brief Overview
Amazon Web Services (AWS) is the cloud computing division of Amazon, offering on-demand computing power, storage, databases, networking, and other IT resources over the internet on a pay-as-you-go basis. Launched in 2006, it is widely regarded as the pioneer and current market leader in cloud computing.

## Global Infrastructure
AWS operates in dozens of geographic Regions worldwide, with each Region made up of multiple isolated Availability Zones (AZs) — physically separate data centers with independent power, cooling, and networking. This design allows customers to build highly available, fault-tolerant applications by spreading resources across multiple AZs within a Region.

## Cloud Management Console
The AWS Management Console is a web-based dashboard that provides centralized access to all AWS services. From the console, users can launch and manage resources such as servers and storage, monitor billing and usage, manage account security, and access AWS support — all without installing any software.

## Four Core Services
1. **Amazon EC2 (Elastic Compute Cloud)** – Provides resizable virtual servers for running applications.
2. **Amazon S3 (Simple Storage Service)** – Object storage service for storing and retrieving any amount of data.
3. **Amazon RDS (Relational Database Service)** – Managed relational database service supporting engines like MySQL, PostgreSQL, and SQL Server.
4. **Amazon VPC (Virtual Private Cloud)** – Lets users provision an isolated, private section of the AWS cloud to launch resources in.

## Three Advantages
1. Broadest range of cloud services and features of any provider, covering compute, storage, AI, IoT, and more.
2. Mature, well-established platform with the largest global infrastructure footprint.
3. Flexible pay-as-you-go pricing with no upfront costs.

## Typical Enterprise Use Cases
- Hosting scalable web and mobile applications
- Big data processing and analytics
- Disaster recovery and backup
- Machine learning model training and deployment
